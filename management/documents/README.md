# 交付文档中心

Hub 首页的“交付文档”可以搜索、预览和下载随包说明。文档是本目录内的普通文件，也可在终端使用 vim 等编辑器查看。

## 文档来源

| 分组 | 内容 |
| --- | --- |
| 交付手册 | Skill 根据当前业务生成的现场安装、验收和 Spug 发布手册 |
| 项目文档 | 开发者在业务仓库 `opskit-delivery.json` 的 documents 字段中指定的资料 |
| 内置说明 | OpsKit 管理端、采集端及其他使用说明 |
| 本地文档 | 直接放在当前目录中的其他资料 |

开发者可以在制包配置中加入文件或目录，例如：

```json
{
  "documents": ["README.md", "docs/部署说明.md", "docs/现场交接.docx", "docs/附件"]
}
```

本次交付所选文档会与镜像和安装器一起校验、进入气隙包，现场不需要联网获取资料。仅选择允许交给现场工程师的文档，不把实际密码、密钥或运行数据作为资料打包。

## 预览与原件

支持 Markdown、文本、PDF、Word `.docx` 及常见图片。Word 可查看正文、表格与内嵌图片；复杂排版以下载的原件为准。旧版 `.doc` 请先在公司转换为 `.docx` 或 PDF 再制包。

Markdown 中的图片和相对文档链接需要把对应文件一并选入；选整个资料目录可以保留原来的相对路径。预览不会执行文档内脚本，也不会自动加载远程图片。

## 文档更新

业务新版本的文档在公司制包时更新，按生成手册在管理机执行文档同步。同步会保留其他业务和手工资料，覆盖旧交付资料前备份并核验。不要直接编辑已计算校验和的发行包；如需现场笔记，放入独立本地文件。
