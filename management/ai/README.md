# AI 故障诊断扩展约定

当前工具包没有实现或启动 AI 服务。本目录只说明后续接入边界；完成管理中心与日志采集链路验收后，再独立选择模型服务、数据范围和访问权限。

建议先提供以下只读能力：

| 能力 | 数据来源与约束 |
| --- | --- |
| 日志检索 | VictoriaLogs `/logs/select/logsql/query`；限定项目、时间范围和返回数量 |
| 主机状态 | Spug 允许访问的主机清单、监控结果；使用单独的集成凭据 |
| 数据库排查 | DBX 官方 MCP / CLI；限制连接和工具，数据库账户本身只授予只读权限 |
| 发布记录 | 已核验的应用版本、发布时间、变更记录与回滚记录 |

不要把管理中心 `.env` 或全部管理员权限交给模型。日志、查询结果和故障报告进入外部模型前，应按项目约定限制和处理其中的业务数据。

本包默认不开放 DBX 远程 MCP。后续启用时，按所固定 DBX 版本的官方说明配置令牌、允许的主机、连接和工具策略；优先由同一管理网络中的独立服务调用。不要把内部 Web API 当作长期稳定的第三方契约。

任意命令执行、数据库写入、重启、发布回滚和备份恢复均未提供给 AI。若以后需要这些动作，应另行实现明确的授权、人工确认和审计，不能仅凭模型输出直接执行。
