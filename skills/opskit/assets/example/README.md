# 独立演练仓库

将本目录复制到临时目录，作为独立仓库调用 Skill。这个小服务只用于验证制包与现场角色操作，不能代替真实客户应用的容器化、数据库迁移或业务验收。

默认目标为龙蜥 8.9 ARM64、端口 19070；应在制包前根据测试机修改 target，使用独立端口、项目名和状态目录。演练镜像使用 Python 官方镜像，服务器源码作为显式只读资源进入包，不需要在现场构建。

先准备对应的真实离线依赖，再使用 build 生成待验收目录。可通过 `--use-local-images` 复用已经验证平台的本地镜像；完整暂存仍需包含 OpsKit 所有镜像。有状态业务请基于真实项目补齐备份和恢复 hook，本例没有这类数据。

首次安装后可制作版本 1.0.1 的新包：修改 application.version 与 APP_VERSION 默认值。已经安装的角色升级时会保留原参数，需通过现场向导修改 APP_VERSION，不能认为更新默认值就会覆盖现场配置。

`deploy/check.sh` 会检查容器内实际 HTTP 返回内容和版本；发布端口的外部可达性另行访问验证。只通过本演练不能给完整 OpsKit 或真实业务填写“已验收”。

`documents` 已选择本 README 和 `docs/` 目录，包含 Markdown 部署说明、随包图片与带表格/内嵌图片的 Word 交接示例。制包后与自动生成的现场/Spug 手册一起显示在 Hub 的交付文档中。Word 用于预览演练，不是客户生产记录。
